# SRE Labs

This repository contains hands-on labs for Linux administration, site reliability engineering, containerized applications, monitoring, and AWS infrastructure.

## Lab Catalog

| Lab | Summary | Start here |
| --- | --- | --- |
| AWS Terraform Lab | Provision an AWS EC2 host with Terraform and run the SRE lab environment on it. | [Build guide](AWS_TF_Lab/How_To_Build_Lab.md) |

| Docker SRE Lab | Explore ticketing and inventory applications alongside Prometheus, Grafana, Loki, Alloy, and Alertmanager. | [75% Complete](Docker_lab/README.md) |

| Linux Navigation Lab | Practice shell navigation and basic file and directory operations. | [Lab guide](Navigation_Lab/README.md) |

|Linux Grep Lab|Practice fixed-string and regular-expression searches, grep options, recursive search, and pipelines.|[Lab guide / Not Tested](Grep_Lab/README.md)|

| Linux Networking Lab | Inspect interfaces, routes, DNS, connectivity, and a local HTTP service. | [Lab guide / Not Tested](Linux_Networking_Lab/README.md) |

| System Info and Processes Lab | Collect system resource information and inspect and manage a test process. | [Lab guide / Not Tested](System_Info_And_Processes_Lab/README.md) |

|Permissions Lab | Add remove permissions with files and folders | [Lab guide / Not Tested](Permissions_Lab/README.md)|

|User/Group Lab| Linux user and group admin | In progress|

## Adding a Lab

Add one row to the catalog with the lab's name, a one-sentence summary, and a relative link to its primary README or build guide. Keep setup steps and exercise details in that lab's folder.
